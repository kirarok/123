# BoilerCalc - Программа поверочного теплового расчёта котлоагрегатов

## Описание программы

**BoilerCalc** — это Windows Forms приложение на .NET 8.0 для выполнения поверочных тепловых расчётов промышленных котлоагрегатов, работающих на твёрдом топливе (угле). Программа производит полный цикл расчётов теплового баланса и экспортирует результаты в формат Word (.docx).

---

## Основные возможности

### 1. Расчётные модули
- **Теоретические объёмы воздуха и продуктов сгорания** — расчёт по формулам на основе элементного состава топлива
- **Таблица 5** — расчёт объёмов трёхатомных газов и водяных паров через 7 газоходов котла (топка → конвективный пароперегреватель → водяной экономайзер → воздухоподогреватель)
- **Таблица 6** — расчёт энтальпий продуктов сгорания в диапазоне температур 100–2500°C с шагом 100°C
- **Таблица 7** — тепловой баланс котлоагрегата с определением:
  - Потерь от химического недожога (q₃)
  - Потерь от механического недожога (q₄)
  - Потерь в окружающую среду (q₅)
  - Потерь с физическим теплом шлака (q₆)
  - КПД брутто (η_бр)
  - Расхода топлива (натурального и условного)

### 2. Базы данных
- **49 марок углей** из различных бассейнов: Донецкий, Кузнецкий, Карагандинский, Экибастузский, Подмосковный, Печорский, Кизеловский, Челябинский, Иркутский (Азейское, Мугунское, Черемховское), Бурятский, Партизанский, Райчихинское, Южный Сахалин и др.
- **50+ моделей котлов**: БКЗ-25...БКЗ-210, Е-25...Е-160, П-50...П-75, КЕ, ДЕ, ТГМП, сверхкритические Пп-1000/1650
- **Термодинамические свойства**: таблицы насыщенной воды/пара (0–370°C, 0.001–22 МПа), перегретого пара (100–600°C), теплофизические свойства газов (воздух, RO₂, N₂, H₂O), энтальпия золы

### 3. Интерфейс
- Автоматическое заполнение параметров при выборе угля/котла из базы
- Возможность ручного ввода всех параметров
- Переключение светлой/тёмной темы оформления
- Валидация входных данных с предупреждениями
- Экспорт результатов в Word с использованием шаблона `Shablon.docx`

## Входные параметры

### Информация о пользователе
- ФИО, название котельного агрегата, вид топлива, марка угля

### Параметры котла
| Параметр | Обозначение | Единица |
|----------|-------------|---------|
| Паропроизводительность | D₀ | т/ч |
| Давление в барабане | Pбар | кгс/см² |
| Давление перегретого пара | Pпп | кгс/см² |
| Температура перегретого пара | Tпп | °C |
| Температура питательной воды | Tпв | °C |
| Объём топочной камеры | Vтоп | м³ |

### Состав топлива (рабочая масса)
Wᴾ (влажность), Aᴾ (зольность), Sᴾ (сера), Cᴾ (углерод), Hᴾ (водород), Nᴾ (азот), Oᴾ (кислород), Qᴾн (низшая теплота сгорания, МДж/кг)

### Параметры топки
αт (коэффициент избытка воздуха), q₃, q₄, a_ун (доля уноса), Δα по газоходам

### Химический состав золы
SiO₂, Al₂O₃, TiO₂, Fe₂O₃, CaO, MgO, K₂O, Na₂O (в %)

## Формулы расчётов

### Теоретический объём воздуха
```
V⁰в = 0.0889·(Cᴾ + 0.375·Sᴾ) + 0.256·Hᴾ - 0.0333·Oᴾ   [м³/кг]
```

### Теоретические объёмы продуктов сгорания
```
V⁰RO₂ = 0.0186·(Cᴾ + 0.375·Sᴾ)   [м³/кг]
V⁰N₂ = 0.79·V⁰в + 0.008·Nᴾ   [м³/кг]
V⁰H₂O = 0.111·Hᴾ + 0.0124·Wᴾ + 0.0161·V⁰в   [м³/кг]
V⁰г = V⁰RO₂ + V⁰N₂ + V⁰H₂O   [м³/кг]
```

### Энтальпии продуктов сгорания
```
I⁰г = V⁰RO₂·(cϑ)RO₂ + V⁰N₂·(cϑ)N₂ + V⁰H₂O·(cϑ)H₂O   [кДж/м³]
I⁰в = V⁰в·(cϑ)в   [кДж/м³]
Iг = I⁰г + (α - 1)·I⁰в + I_зл   [кДж/кг]
```

### КПД брутто (обратный баланс)
```
η_бр = 100 - (q₂ + q₃ + q₄ + q₅ + q₆)   [%]
```
